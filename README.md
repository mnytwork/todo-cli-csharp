# ToDo CLI Application (C#)

A command-line ToDo application built in C#. It allows users to manage tasks through a simple menu-driven interface.

## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Input validation to prevent crashes

## Tech Stack
- C#
- .NET Console Application
- Pastel (for colored output)

## How to Run
1. Clone the repository
2. Navigate to the project folder
3. Run:
   dotnet run
